# ArcSLA: Verifiable Service Settlement

> Built with Arc Studio - money-powered apps in minutes

This is the **project memory** - what Arc Studio remembers about building this app. It helps future agents (or humans) understand and extend the project.

## What This App Does

ArcSLA is a USDC escrow protocol on Arc: customers pre-fund agreements, a trusted verifier signs EIP-712 fulfillment attestations that anyone can submit to release funds to the provider, and customers are refunded after the deadline. No owner, no fees, no upgrades. See `docs/SECURITY.md`.

## Tech Stack

- Frontend: React 18, Vite, TypeScript, Tailwind CSS
- Web3: wagmi v2, viem v2, ConnectKit
- Contracts: Solidity 0.8.28 + Foundry. Sources in `contracts/`, unit tests in `contracts/test/*.t.sol`. Build with `bun run contracts:build` (`forge build`), test with `bun run contracts:test` (`forge test`).
- Wallet: injected (MetaMask, etc.)
- Chain: Arc Testnet (Chain ID: 5042002, imported from `viem/chains`)
- Token: USDC (6 decimals) (Address: 0x3600000000000000000000000000000000000000, Chain: Arc Testnet)
- Toasts: Sonner

## Key Files

- `contracts/ArcSLA.sol` - the protocol (201 passing Foundry tests in `contracts/test/`; review in `docs/SECURITY_REVIEW.md`)
- `src/App.tsx` - route table; pages in `src/pages/`, shared UI in `src/components/`
- `src/state/ChainData.tsx` - single shared read of agreements, events and chain clock
- `src/lib/networks.ts` - per-network ArcSLA address + deploy block (testnet and mainnet registered separately); `src/lib/env.ts` - network selection and guards (VITE_DEFAULT_NETWORK, VITE_ARC_CHAIN_ID legacy, VITE_USDC_ADDRESS must be unset)
- `src/contracts/ArcSLA.abi.ts` - generated by `bun run abi:export`; do not hand edit
- `src/components/` - UI components
- `src/config.ts` - wagmi config (chains, connectors, transports)

## Mainnet status

Preparation only. Nothing is deployed on Arc Mainnet. `contracts/script/DeployArcSLA.s.sol` accepts only Arc Testnet/Mainnet and the official USDC address; mainnet needs `ARCSLA_MAINNET_CONFIRM`. The frontend defaults to Arc Testnet; on mainnet it shows a real-funds warning and blocks all transactions until the contract is verified onchain and the warning is acknowledged. See `docs/MAINNET_DEPLOYMENT.md` and `docs/DEPLOYMENT_READINESS.md`.
